Lua assembly

What is a names list?

A names list is a .txt file containing Lua names you want to keep unchanged when minifying. Other names may be shortened to make the code smaller.

Put one name per line, matching its spelling and capitalization:

player_score
update_player
# This is a comment

Blank lines and lines starting with # are ignored. Add the .txt file using Add Files, then choose it here.

It only affects Minify. Keep all names preserves every name, so a list is unnecessary with that option enabled.

The CLI does not yet implement token optimization for raw Lua builds.

Supported file types

      
    

    

      
Select several files at once, or drop them into the workspace.

      

        
.p8 · Text cartridgeInspect code and statistics, search, format or minify Lua, and export a cartridge. Use cartridges as section sources in Build.

        
.p8.png · Image cartridgeA PICO-8 cartridge encoded in a PNG image. Inspect, transform, and use it in Build like a text cartridge. Ordinary .png images are not supported.

        
.lua · Lua sourceChoose an added Lua file as the Build entry or use it as a require() module. For nested module paths, use Select module folder in Build.

        
.txt · Names to preserveSelect this file under Names to preserve when minifying in Transform or Build. List one identifier per line; blank lines and lines starting with # are ignored.
